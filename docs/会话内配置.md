# 📖 会话内配置指南

鲸鱼娘插件的所有配置都可以**在对话里完成**，不需要手动编辑 yml 文件。核心是 **`settings` 工具**。

## 快速上手

```text
你：「看下配置」
鲸鱼娘：settings get → 列出全部功能模块和当前值

你：「开启群友模式，屏蔽群123，我叫小鲸」
鲸鱼娘：settings set friend.nickname 小鲸
       → settings set friend.blacklist.groups+=["123"]
       → settings set friend.enabled true

你：「定时汇报关掉」
鲸鱼娘：settings set enableReports false

你：「只允许我指挥」
鲸鱼娘：settings set accessControl.mode whitelist

你：「保存当前记忆」
鲸鱼娘：总结本次会话 → save_memory(...)
```

## settings 工具

```
settings get [路径]           # 查看配置（不带路径 = 全部模块总览）
settings set <路径> <值>      # 修改配置
```

- **get**：列出 6 大模块（📢通知 / 📅定时汇报 / 👥群友 / 🔐访问控制 / 🧠记忆 / 🎓学习）及当前值
- **set**：按路径修改，支持布尔、字符串、数组（`+=` 追加）
- 修改后**重启 DSH 生效**（工具会提示）

## 全部配置路径

### 📢 通知（notify）

| 路径 | 含义 | 示例 |
| --- | --- | --- |
| `defaultChannel` | 默认通知渠道 | `settings set defaultChannel feishu_bot` |

### 📅 定时汇报（reports）

| 路径 | 含义 | 示例 |
| --- | --- | --- |
| `enableReports` | 定时汇报总开关（默认关） | `settings set enableReports true` |

汇报计划在 preset 的 `reports` 数组里配置（见示例配置），格式：
- `daily:09:00` — 每天 09:00
- `every:30` — 每 30 分钟

### 👥 群友模式（friend.*，独立文件）

群友模式配置存在 `$DSH_HOME\friendmode\config.json`（settings 工具读写它），独立于主配置。

| 路径 | 含义 | 示例 |
| --- | --- | --- |
| `friend.enabled` | 群友模式开关 | `settings set friend.enabled true` |
| `friend.nickname` | 群里的称呼（首次开启必须先设） | `settings set friend.nickname 小鲸` |
| `friend.readOnly` | 只读模式（只回复不执行修改） | `settings set friend.readOnly true` |
| `friend.blacklist.groups` | 屏蔽群（`+=` 追加） | `settings set friend.blacklist.groups+=["123"]` |
| `friend.blacklist.users` | 屏蔽用户（`+=` 追加） | `settings set friend.blacklist.users+=["999"]` |

**群友模式的提示词和记忆**：
- 回复风格：编辑 `$DSH_HOME\friendmode\prompts.md`（默认：简短、像真实网友）
- 聊天记忆：`$DSH_HOME\memory\friend\memory.jsonl`

### 🔐 访问控制（accessControl）

| 路径 | 含义 | 示例 |
| --- | --- | --- |
| `accessControl.mode` | `whitelist`=仅白名单 / `open`=所有人 | `settings set accessControl.mode whitelist` |
| `accessControl.allowedUsers.qq` | 白名单 QQ（`+=` 追加） | `settings set accessControl.allowedUsers.qq+=["123"]` |
| `accessControl.allowedUsers.feishu` | 白名单飞书 open_id | `settings set accessControl.allowedUsers.feishu+=["ou_xxx"]` |

### 🧠 记忆模式

| 操作 | 说 |
| --- | --- |
| 保存记忆 | 「保存当前记忆」「记住这个」「总结一下存起来」→ `save_memory` |
| 恢复记忆 | 「恢复XX的记忆」「上次怎么做的」→ `recall_memory`（先搜记忆库文档，再翻官方会话） |
| 记忆位置 | `$DSH_HOME\memory\`（conversations=跨会话 / friend=群友 / summaries=手动总结） |

### 🎓 学习模式

| 操作 | 说 |
| --- | --- |
| 记录技能 | 「把XX记下来」→ `learn_skill`（先询问确认） |
| 调取技能 | 「上次XX怎么做的」→ `recall_skill` |
| 知识库位置 | `$DSH_HOME\knowledge\` |

## 完整对话示例

```text
你：鲸鱼娘，看下配置
鲸鱼娘：📋 配置总览
  📢 通知 · 默认渠道: ""
  📅 定时汇报 · 开关: false
  👥 群友模式 · 开关: false · 称呼: 未设置
  🔐 访问控制 · 模式: whitelist
  ...

你：开启群友模式，让大家叫我小鲸，屏蔽群88888888
鲸鱼娘：（先确认只读？）你希望只读模式吗（只回复不执行操作）？
你：不用，正常就行
鲸鱼娘：已设置称呼「小鲸」→ 已屏蔽群 88888888 → 群友模式已开启 ✅

你：以后每天9点汇报一下吧
鲸鱼娘：settings set enableReports true（需在配置里加 reports 计划）重启后生效
```

## 注意事项

1. **重启生效**：settings 修改写入配置文件，需要重启 DSH 才加载
2. **密钥不在这**：邮箱/飞书密钥走环境变量（见外部服务配置指南），settings 不碰
3. **群友首次开启**：必须先设称呼（`friend.nickname`），鲸鱼娘会引导
4. **yml 兜底**：settings 改不了的（如渠道的 host/key）仍可手动编辑 preset 文件
