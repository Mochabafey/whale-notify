# 📖 外部服务配置指南

鲸鱼娘插件需要连接外部服务才能收发消息。本文按「QQ（NapCat）→ 飞书开放平台 → 邮箱」顺序，给出完整的申请与配置步骤（含踩坑经验）。

## 一、QQ（NapCat / OneBot）

### 1.1 原理

| 角色 | 说明 |
| --- | --- |
| **NapCat** | 运行在本机的 QQ 机器人框架（OneBot 协议），注入已登录的 QQ |
| **机器人 QQ** | 被 NapCat 注入的 QQ 号（如 Aria麦麦），是鲸鱼娘的"马甲" |
| **你的 QQ** | 你本人的 QQ 号，向机器人发消息指挥 |

### 1.2 安装 NapCat

> ⚠️ **不要用 OneKey 版**（`NapCat.Shell.Windows.OneKey.zip`）——它内置 QQ 下载且易 404。用标准 Shell 版。

1. 到 [NapCat Releases](https://github.com/NapNeko/NapCatQQ/releases) 下载 **`NapCat.Shell.zip`**
2. 解压到任意目录（如 `D:\NapCatShell`）
3. 确保 QQ NT 版已安装（`C:\Program Files\Tencent\QQNT\`，新版 QQ 都行）
4. 双击 **`launcher-user.bat`**（用户版，无需管理员）启动
5. 首次会拉起 QQ 登录 → **扫码/登录机器人 QQ**（如 Aria麦麦）
6. 登录后 NapCat 自动运行，WebUI 在 `http://127.0.0.1:6099`

### 1.3 启用 OneBot 服务

NapCat 登录后生成 `config\onebot11_<机器人QQ号>.json`。编辑它启用 HTTP + 反向 WS：

```json
{
  "network": {
    "httpServers": [
      { "name": "http-server", "enable": true, "port": 3000, "host": "127.0.0.1",
        "enableCors": true, "enableWebsocket": false, "messagePostFormat": "array",
        "token": "", "debug": false }
    ],
    "httpSseServers": [],
    "httpClients": [],
    "websocketServers": [],
    "websocketClients": [
      { "name": "dsh-whale-notify", "enable": true, "url": "ws://127.0.0.1:3001",
        "messagePostFormat": "array", "reportSelfMessage": false, "token": "",
        "reconnectInterval": 5000, "debug": false }
    ],
    "plugins": []
  }
}
```

- **HTTP 3000**：插件的 `sendQQ` 用它发消息（OneBot API）
- **反向 WS 3001**：NapCat 主动连插件的接收端（插件在 DSH 里监听 3001）

改完**重启 NapCat**（关掉再 `launcher-user.bat`）。

### 1.4 验证

```powershell
# 测试 OneBot API（应返回机器人 QQ 信息）
Invoke-WebRequest -Uri "http://127.0.0.1:3000/get_login_info" -Method Post -ContentType "application/json" -Body '{}'
# 测试发消息（发给你的 QQ）
Invoke-WebRequest -Uri "http://127.0.0.1:3000/send_private_msg" -Method Post -ContentType "application/json" -Body '{"user_id": 你的QQ, "message": "测试"}'
```

### 1.5 插件配置（preset）

```yaml
    qq:
      httpBase: 'http://127.0.0.1:3000'   # OneBot HTTP
      accessToken: ''                     # 若 NapCat 配了 token 则填
      qq: '你的QQ号'                      # 通知发往：你本人
      groupId: ''                         # 或填群号
      wsPort: 3001                        # 插件监听反向 WS 的端口
      targetSession: ''                   # 可选：QQ 消息注入哪个 DSH 会话
```

### 1.6 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| OneKey 安装 404 | 内置 QQ 下载链接失效 | 用 Shell 版 + 已安装的 QQ |
| `Error Code: 2 找不到 QQ.exe` | NapCat 便携目录无 QQ | 用 Shell 版（从注册表找 QQ） |
| 3001 端口冲突 | 多个进程抢端口 | 关掉多余的 DSH/测试脚本 |
| 版本不兼容 | QQ 版本过新/过旧 | 尽量用最新 NapCat + 最新 QQ |

## 二、飞书开放平台（自建应用）

### 2.1 创建应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app) → **创建企业自建应用**
2. 记下 **App ID**（`cli_xxx`）和 **App Secret**

### 2.2 配置应用（必须全部完成）

| 配置 | 操作 |
| --- | --- |
| **权限** | 权限管理 → 开通 **`im:message`**（获取与发送单聊、群组消息）等 |
| **事件订阅** | 事件与回调 → 订阅方式选 **「使用长连接接收事件/回调」** |
| **事件** | 添加 **`im.message.receive_v1`**（接收消息） |
| **发布** | 版本管理与发布 → 创建版本 → **申请发布**（自建应用改配置必须发布才生效！） |

> ⚠️ **长连接模式必须在后台选**，否则插件连不上。改完配置一定要**发布新版本**。

### 2.3 环境变量

```powershell
[Environment]::SetEnvironmentVariable("FEISHU_APP_ID", "cli_xxx", "User")
[Environment]::SetEnvironmentVariable("FEISHU_APP_SECRET", "你的AppSecret", "User")
```

> ⚠️ 设置环境变量后**必须新开窗口**启动 DSH（旧窗口读不到新变量）。

### 2.4 插件配置（preset）

```yaml
    feishuBot:
      appId: '$ENV:FEISHU_APP_ID'
      appSecret: '$ENV:FEISHU_APP_SECRET'
      receiveId: 'oc_xxxxxxxx'            # 你的私聊 chat_id（给机器人发条消息，从日志/事件中可看到）
      receiveIdType: 'chat_id'
      targetSession: ''
```

### 2.5 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 连不上长连接 | 后台没选「长连接」或没发布 | 检查订阅方式 + 发布新版本 |
| 收不到消息 | 没订阅 `im.message.receive_v1` | 添加事件并发布 |
| 发消息失败 | 缺 `im:message` 权限 | 开通权限并发布 |
| `ou_xxx` 是啥 | 你的飞书 open_id | 给机器人发条消息，插件日志 `feishu_in` 里能看到 |

## 三、邮箱（SMTP / IMAP）

### 3.1 各邮箱的"授权码"

> ⚠️ **每个邮箱的授权码互不通用**，且不是登录密码。

| 邮箱 | 授权码叫法 | 在哪拿 |
| --- | --- | --- |
| 飞书邮箱 | 专用密码 | 飞书网页版 → 设置 → 邮箱设置 → 外部收发信 |
| QQ 邮箱 | 授权码 | QQ 邮箱 → 设置 → 账户 → 开启 SMTP/IMAP |
| 163 邮箱 | 客户端授权码 | 163 邮箱 → 设置 → POP3/SMTP/IMAP |
| Gmail | 应用专用密码 | Google 账户 → 两步验证 → 应用专用密码 |

### 3.2 常用服务器参数

| 邮箱 | SMTP（发） | IMAP（收） |
| --- | --- | --- |
| 飞书 | `smtp.feishu.cn:587`（STARTTLS） | `imap.feishu.cn:993` |
| QQ | `smtp.qq.com:465` | `imap.qq.com:993` |
| 163 | `smtp.163.com:465` | `imap.163.com:993` |
| Gmail | `smtp.gmail.com:587` | `imap.gmail.com:993` |

### 3.3 环境变量

```powershell
[Environment]::SetEnvironmentVariable("MAIL_PASS", "你的授权码", "User")
```

### 3.4 插件配置（preset）

```yaml
    smtp:
      host: 'smtp.feishu.cn'
      port: 587                     # 587=STARTTLS(secure:false)；465=隐式SSL(secure:true)
      secure: false
      user: '发信账号@example.com'
      pass: '$ENV:MAIL_PASS'
      from: '发信账号@example.com'
      to: ['收件邮箱@example.com']
    imap:
      host: 'imap.feishu.cn'
      port: 993
      secure: true
      user: '发信账号@example.com'
      pass: '$ENV:MAIL_PASS'        # 同一个授权码
      mailbox: 'INBOX'
    pollIntervalMs: 30000           # 每 30 秒轮询收件箱
```

> 飞书邮箱实测：**587 + STARTTLS 比 465 更稳**（部分网络 465 会超时）。

## 四、配置检查清单

- [ ] NapCat 运行中（`launcher-user.bat`），HTTP 3000 通
- [ ] 飞书应用已发布（长连接 + `im.message.receive_v1` + `im:message` 权限）
- [ ] 环境变量已设（`FEISHU_APP_ID/SECRET`、`MAIL_PASS`）
- [ ] 已**新开窗口**重启 DSH
- [ ] preset 的 `qq` / `feishuBot` / `smtp` / `imap` 段已配置
- [ ] 访问控制白名单里有你的 QQ / 飞书 open_id
